Grocery Inventory Management
🛒 Grocery Inventory Management System (Flask + SQLite)

A simple web-based **Grocery Inventory Management System** built using **Flask, SQLite, Bootstrap, and JavaScript**.  
This project helps you manage grocery items by storing details like **category, manufacturing date, expiry date, quantity, and price**.  
It also provides alerts for **low stock** and **products expiring soon**.

---

✨ Features

✅ Add new grocery products  
✅ Edit product details  
✅ Delete products  
✅ View all products in a table  
✅ Filter products by category  
✅ Expiry alert (items expiring within 7 days)  
✅ Low stock alert (quantity ≤ 10)  
✅ Voice + Popup alert system  
✅ Data stored permanently in **SQLite database**

---

🧰 Technologies Used

- Python (Flask)
- SQLite3
- HTML
- Bootstrap 5
- JavaScript (Fetch API)

 📝 How It Works
➕ Add Product

Fill the form and click Add to save the product into the database.

✏️ Edit Product

Click Edit, update the details, and click Update.

🗑️ Delete Product

Click Delete to remove the product.

🔍 Filter by Category

Select a category from the dropdown to view items of that category.

⚠️ Check Expiry & Low Stock

Click Check Expiry to get:

Products expiring within 7 days

Products having quantity ≤ 10
You will get a popup alert + voice alert.
